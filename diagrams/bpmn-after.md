# Бизнес-процесс модерации контента (после внедрения ИИ-системы)

## Описание

Диаграмма изображает процесс модерации комментариев после внедрения ML-системы анализа тональности. ИИ-модель автоматически классифицирует входящие комментарии в реальном времени, перенаправляя подозрительный контент модераторам с предзаполненными рекомендации. Ручная обработка сокращается до ~3-5% от общего объёма.

## Диаграмма BPMN

```mermaid
flowchart TD
    Start([Пользователь публикует комментарий]) --> Ingest[API Gateway: приём комментария]
    Ingest --> Preprocess[Предобработка: очистка, токенизация, эмбеддинг]
    Preprocess --> MLModel[ML-модель анализа тональности]
    MLModel --> Score{Оценка модели}

    Score -->|Негатив ≥ 0.85| AutoRemove[Автоматическое скрытие / пометка]
    Score -->|Негатив 0.5–0.85| Queue[Очередь на ручную проверку с подсказкой ИИ]
    Score -->|Нейтральный / позитив < 0.5| PublishAuto[Автоодобрение и публикация]

    Queue --> HumanReview[Модератор подтверждает / отклоняет рекомендацию]
    HumanReview -->|Подтверждает удаление| Remove2[Удалить комментарий]
    HumanReview -->|Не согласен — ложно-положительный| Reinstate[Восстановить + подать сигнал дообучения]

    AutoRemove --> Log[Логирование в БД аналитики]
    Remove2 --> Log
    Reinforce[Сигнал дообучения] --> FeedbackLoop[(Накопление для дообучения)]
    Reinstate --> PublishAuto
    PublishAuto --> Dashboard[Дашборд аналитики контента]

    Log --> Dashboard
    FeedbackLoop -->|Периодическое дообучение| MLModel
    Dashboard --> End([Конец процесса])
    Reinstate --> End
    Remove2 --> End
```

## Ключевые изменения, которые вносит ИИ-система

| Аспект | До | После |
|---|---|---|
| Покрытие | < 5% комментариев | 100% комментариев |
| Время реакции | 2–24 часа | < 1 секунда (автоматически) / < 15 мин (человек) |
| Стоимость | 30+ модераторов | 5–7 модераторов для граничных случаев |
| Объективность | Субъективные решения | Консистентная модель + человеческий контроль |
| Риск штрафов РКН | Высокий | Минимальный (автоматическое скрытие) |
| Аналитика | Отсутствует | Дашборд тональности в реальном времени |
