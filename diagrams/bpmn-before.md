# Бизнес-процесс модерации контента (до внедрения ИИ-системы)

## Описание

Диаграмма изображает текущий (ручной) процесс модерации комментариев в социальной сети. Модераторы вручную читают выборочные комментарии, принимают решения об удалении и escalation. Процесс медленный, дорогой и субъективный.

## Диаграмма BPMN

```mermaid
flowchart TD
    Start([Пользователь публикует комментарий]) --> Filter{Автоматический фильтр стоп-слов}
    Filter -->|Содержит стоп-слово| Queue1[Очередь на ручную модерацию]
    Filter -->|Не содержит стоп-слово| Publish[Комментарий опубликован]

    Queue1 --> ManualCheck[Модератор читает комментарий вручную]
    ManualCheck --> Decision1{Оценка модератором}
    Decision1 -->|Негатив / нарушение| Remove[Удалить комментарий]
    Decision1 -->|Допустимый| Approve[Одобрить]
    Decision1 -->|Неопределённый| Escalate[Передать старшему модератору]

    Escalate --> SeniorReview[Старший модератор проверяет]
    SeniorReview --> Decision2{Решение старшего}
    Decision2 -->|Нарушение| Remove
    Decision2 -->|Допустимый| Approve

    Remove --> Report1[Фиксация в журнале]
    Approve --> Publish
    Report1 --> End([Конец процесса])
    Publish --> End

    style Start fill:#e1f5fe
    style End fill:#ffebee
    style ManualCheck fill:#fff3e0
    style SeniorReview fill:#fff3e0
    style Decision1 fill:#fce4ec
    style Decision2 fill:#fce4ec
```

## Узкие места текущего процесса

| Проблема | Оценка |
|---|---|
| Пропускная способность | ~500 000 комментариев/день; ручная модерация покрывает < 5% |
| Время реакции | От 2 до 24 часов до принятия решения |
| Субъективность | Разные модераторы по-разному оценивают граничные случаи |
| Стоимость | 30+ модераторов в смену, высокой текучка |
| Риск штрафов РКН | Неприемлемый контент может оставаться опубликованным часами |
